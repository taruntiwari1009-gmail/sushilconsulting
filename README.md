# Sushil Consulting

A responsive, single-page consulting website focused on data strategy, data enablement, analytics and business transformation.

## What the site includes

- Responsive navigation and landing page
- Consulting service and industry-solution sections
- Data transformation methodology and impact comparisons
- Illustrative Chart.js dashboards and interactive tabs
- A Three.js network-globe illustration
- FAQ accordion and contact calls to action

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- [Chart.js](https://www.chartjs.org/)
- [Three.js](https://threejs.org/)
- Particles.js
- Font Awesome and Google Fonts

Third-party libraries and fonts are loaded from CDNs. An internet connection is required for those assets.

## Run locally

No build step or package manager is required.

1. Clone the repository.
2. Open `index.html` in a browser, or serve the folder with any static web server.

For example, with Python:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Data and demo disclaimer

The charts use illustrative sample values, and the 3D network globe generates decorative points and connections in the browser. They are not connected to a live analytics platform and should not be presented as actual client results.

## Deployment

The site is a static HTML page and can be hosted on GitHub Pages, Netlify, or another static hosting provider. Ensure the configured contact email and WhatsApp link are current before publishing.

## Before production

- Verify all business claims, service descriptions and contact details.
- Replace any placeholder social links with the correct company profiles.
- Review external CDN dependencies and consider pinning versions or self-hosting critical assets.
- Test navigation, charts and the 3D illustration on mobile devices and browsers without WebGL support.
